¡Bienvenido/a a **Wenlor**! Este es un programa interactivo desarrollado en Python que permite convertir una cantidad ingresada en Pesos Colombianos (COP) a cuatro de las divisas más populares del mundo.

## Características

El programa realiza la conversión de Pesos Colombianos a las siguientes monedas utilizando tasas de cambio predefinidas:
*   **Dólares (USD)**
*   **Euros (EUR)**
*   **Yuanes (CNY)**
*   **Pesos Mexicanos (MXN)**

El sistema solicita el nombre del usuario para una experiencia personalizada y muestra el equivalente exacto de su dinero en las cuatro divisas de forma simultánea.

## Tecnologías utilizadas

*   **Lenguaje:** Python 3
*   **Entorno:** Visual Studio Code / Terminal

## Instrucciones de uso

1. Abre tu terminal de preferencia.
2. Navega hasta la carpeta donde se encuentra el proyecto.
3. Ejecuta el archivo principal con el siguiente comando:
   ```bash
   python convertidor_divisas_Wenlor.py


## Ten en cuenta
Cuando uses el convertidor y te pida la cantidad de pesos, **escríbela puramente en números, sin puntos ni comas**. Por ejemplo, escribe `50000` y no `50.000`. Si le pones signos de puntuación, el programa se confunde y mostrará un error.

## Lo que le quiero agregar después
Por ahora el programa es sencillo, funcional y va directo al grano, pero en el futuro me gustaría mejorarlo con estas ideas:
*   **Un ciclo continuo:** Para que al terminar una conversión pregunte si quiero hacer otra, sin tener que volver a ejecutar el programa desde cero.
*   **Manejo de errores:** Un sistema para que el programa no "explote" si alguien pone letras por accidente, sino que le avise amablemente al usuario.
*   **Redondeo:** Limpiar la cantidad de decimales en los resultados para que se vea más parecido al formato real del dinero.
