# Convertidor de Divisas - Wenlor

¡Bienvenido/a a **Wenlor**! Este es un programa interactivo desarrollado en Python que permite convertir una cantidad ingresada en Pesos Colombianos (COP) a cuatro de las divisas más populares del mundo.

## Características

El programa realiza la conversión de Pesos Colombianos a las siguientes monedas utilizando tasas de cambio predefinidas:
*   **Dólares (USD)**
*   **Euros (EUR)**
*   **Yuanes (CNY)**
*   **Pesos Mexicanos (MXN)**

El sistema solicita el nombre del usuario para una experiencia personalizada y muestra el equivalente exacto de su dinero en las cuatro divisas de forma simultánea.

## Tecnologías utilizadas

*   **Lenguaje:** Python 3
*   **Entorno:** Visual Studio Code / Terminal
